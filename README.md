# Orso Borotalco

Platform dolce: aiuta l’orso a raccogliere le stelle, trovare il borotalco e arrivare in bagno.

**Gioca online:** https://lallievi-cell.github.io/orso-borotalco/

## Controlli

- Computer: frecce o A/D per muoverti, W o Spazio per saltare, S o freccia giù per scendere dalle piattaforme.
- Telefono: pulsanti a schermo.

Il progresso resta salvato in questo browser.

## In locale

```bash
npm install
npm run dev
```

Il sito pubblico si aggiorna da solo a ogni push su `main` (GitHub Pages).
